# 51 单片机学习工程集

从零开始学 8051（51）单片机的代码仓库。**每个项目一个独立文件夹**，源码 + 工程文件都在里面，克隆下来就能编译下载。

## 开发环境

| 项目 | 说明 |
| --- | --- |
| 芯片 | **AT89C52**（Keil 里的器件型号；实际开发板多为 STC89C52RC，两者 8051 内核兼容） |
| 晶振 | **11.0592 MHz**（`2-2`、`2-3` 两个早期工程的软件延时按 **12 MHz** 写的，源码注释里有标注） |
| 编译器 | **Keil C51**（uVision5） |
| 下载 | **STC-ISP**（图形界面）或 `stcflash.py`（命令行，见各 EIDE 工程的 `tools/`） |

## 两种工程格式

**1. Keil uVision 工程（`2-x`）**

```
2-1点亮一个LED/
├── main.c              # 源码
├── led_test.uvproj     # 工程文件 ← 双击这个打开
├── led_test.uvopt      # 调试/窗口配置
├── Objects/            # 编译输出（已被 .gitignore 忽略）
└── Listings/           # 列表文件（已被忽略）
```

双击 `.uvproj` → `F7`（Build）→ 生成的 `Objects/*.hex` 拿去下载。

**2. EIDE 工程（`3-x`、`7-1`、模板）**

```
3-1 独立按键控制LED亮灭/
├── src/main.c          # 源码
├── .eide/eide.yml      # 工程配置
├── p3_1.code-workspace # VSCode 工作区 ← 打开这个
├── tools/stcflash.py   # 命令行下载脚本
└── build/Debug/        # 编译输出（已被忽略）
```

用 VSCode + EIDE 插件打开 `*.code-workspace`，构建后输出 `build/Debug/*.hex`。

⚠️ 这两个地方是**跟本机绑定**的，换电脑要改：

- `.eide/eide.yml` 的 include 路径写的是 `../../Keil5/C51/INC`，即假设 Keil C51 装在 **`D:\Keil5\C51`**；
- 烧录命令里的串口默认 **`COM3`**（`eide.yml` 的 `uploadConfigMap`），按自己板子的实际串口改。

## 关于 .gitignore

编译产物**全部忽略**（`Objects/`、`Listings/`、`build/`、`*.hex` 等），仓库里只有源码和工程配置，历史记录干净。克隆后编译一次就能重新生成 `.hex`。

如果就是想把某个固件也存进仓库（比如方便直接下载烧录），强制添加即可：

```bash
git add -f "2-1点亮一个LED/Objects/led_test.hex"
```
