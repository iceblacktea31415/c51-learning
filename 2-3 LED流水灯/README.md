# 2-3 LED 流水灯

## 功能

8 颗 LED 从 D1 到 D8 **依次点亮**，每颗亮 500ms，走到头再从头开始。

## 代码要点

```c
P2=0xFE;  Delay500ms();   // 1111 1110  → D1
P2=0xFD;  Delay500ms();   // 1111 1101  → D2
P2=0xFB;  Delay500ms();   // 1111 1011  → D3
P2=0xF7;  Delay500ms();   // 1111 0111  → D4
P2=0xEF;  Delay500ms();   // 1110 1111  → D5
P2=0xDF;  Delay500ms();   // 1101 1111  → D6
P2=0xBF;  Delay500ms();   // 1011 1111  → D7
P2=0x7F;  Delay500ms();   // 0111 1111  → D8
```

- 这 8 个值就是"**一个 0 从左往右挪一位**"：0 在哪个位置，哪颗 LED 亮。因为 LED 低电平点亮。
- 写法很直白，但**不好改**：想改速度得动 8 处延时，想改方向得重排 8 个数。
- 注意这一版用的是 `Delay500ms()` 固定延时，跟 `2-2` 一样是按 12MHz 那套参数生成的。

## 和 2-4 的区别

| | 2-3 | 2-4 |
| --- | --- | --- |
| 顺序 | D1 → D8 | D8 → D1（反向） |
| 延时 | 固定 `Delay500ms()` | 可传参 `DelayXms(x)` |
