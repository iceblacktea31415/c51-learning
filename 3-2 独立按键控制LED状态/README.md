# 3-2 独立按键控制 LED 状态

## 功能

按一次 K1（P3.1）→ D1 的状态**翻转**一次（灭变亮、亮变灭）。这是"按一下、锁存住"的效果。

## 代码要点

```c
if(P3_1==0){
    DelayXms(10);        // ① 消抖：等抖动过去
    while(P3_1==0);      // ② 死等松手，保证一次按下只算一次
    DelayXms(10);        // ③ 松手后再消抖
    P2_0=~P2_0;          // ④ 翻转 D1
}
```

四步是标准的**软件消抖 + 松手检测**流程：

| 步骤 | 作用 | 少了会怎样 |
| --- | --- | --- |
| ① 10ms 延时 | 跨过按下抖动 | 一次按下被识别成好几次 |
| ② 等松手 | 长按也只响应一次 | 按住不放会疯狂翻转 |
| ③ 松手延时 | 跨过松开抖动 | 松手瞬间可能再触发一次 |
| ④ `~P2_0` | 位取反翻转 | — |

- `P2_0 = ~P2_0`：`~` 是按位取反，位变量上就是 `0↔1`。
- 相比 `3-1` 的"按住亮松开灭"，这一版是**边沿触发**（状态翻转），更接近真实按钮的用法。

## 工程格式（EIDE）
