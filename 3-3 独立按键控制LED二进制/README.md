# 3-3 独立按键控制 LED 二进制（启停流水灯）

## 功能

- 按一次 K1（P3.1）→ 流水灯**开始跑**；
- 再按一次 → **停下来**（8 颗全灭）。

## 代码要点

**1. 用 `flag` 做启停状态**

```c
bit flag=0;
if( P3_1==0 ){
    DelayXms(10);  while( P3_1==0 );  DelayXms(10);   // 消抖 + 等松手
    if( flag==0 ){ flag=1; }        // 没在跑 → 开始
    else{ flag=0; P2=0xFF; }        // 在跑 → 停，并全灭
}
```

沿用了 `3-2` 的消抖流程，把"翻转 LED"换成"翻转 `flag`"。

**2. 不用阻塞延时，改用计数累加**

```c
if(flag==1){
    tick = tick + 8;
    if (tick >= 500){
        tick = 0;
        P2 = ~(1 << i);      // 只有第 i 个 LED 亮
        i++;
        if (i >= 8){
            i = 0;           // 走完 8 颗回到 D1
        }
    }
}
```

- `1 << i` 造出"第 i 位是 1、其余 0"的数，取反后就是**只有第 i 颗 LED 低电平**。比 `2-3` 里手写 8 个 0xFE/0xFD… 更容易扩展。
- `tick` 每次循环加 8，累到 500 才走一步——这就是**非阻塞延时**的思路：循环本身不影响节奏判断以外的任何事。

**⚠️ 实际运行会很快**：因为本工程把 `//DelayXms(10);` 注释掉了，`tick` 的增长速度完全取决于 CPU 跑一圈主循环多快，`tick` 到 500 可能只要几毫秒。把那一行的注释去掉，才是约 **10ms × 500/8 ≈ 0.6 秒**走一步的正常节奏。

> 正确的做法是在主循环里用**定时器中断**产生固定 tick，这也是后面章节要学的内容。
