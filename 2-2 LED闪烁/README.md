# 2-2 LED 闪烁

## 功能

P2.0 上的 LED 以 **500ms 亮 / 500ms 灭** 的节奏持续闪烁。

## 代码要点

```c
void Delay500ms()		//@12.000MHz
{
	unsigned char i, j, k;
	_nop_();
	i = 4; j = 205; k = 187;
	do { do { while (--k); } while (--j); } while (--i);
}
```

- **三层嵌套空循环**凑出 500ms：`k` 最内层空转，`j`、`i` 外层计数。这种延时是靠"数指令周期"算出来的，跟晶振频率强绑定。
- 注释 `//@12.000MHz` 说明这段代码是按 **12MHz** 生成的。本板用 11.0592MHz 时，实际延时约 **458ms**，肉眼基本看不出差别，但要精确计时就得按 11.0592 重算。
- `_nop_()` 来自 `<INTRINS.H>`，是一条空操作指令，用来对齐时序。
- 闪烁本质就是 `P2 = 0xFE`（亮）→ 延时 → `P2 = 0xFF`（灭）→ 延时，无限循环。

## 缺点 / 下一步

软件延时期间 **CPU 完全被占用**，什么都不能干。`2-4` 把它改成了可传参的 `DelayXms(x)`，`3-3` 则改成非阻塞计数。
